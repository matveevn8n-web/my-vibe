# New Volga

Одноэкранная точка входа Matveev Apartments: квартиры посуточно у Волги в центре Самары. Главная помещается в один экран, в центре модуль бронирования Bnovo. Квартиры, условия, FAQ и контакты — отдельные страницы.

Исходники лежат в `new-volga/`. Готовый статический сайт — в `docs/`. Корневой `index.html` репозитория — другой проект, его сборка не трогает.

Городской номер City #151 продан и в данные не входит.

## Локально

Нужен Node.js 22 (сборка) и любой статический сервер.

```bash
cd new-volga
node src/build.mjs
python3 -m http.server 4173 --directory ../docs
```

Открыть http://127.0.0.1:4173/

Сайт рассчитан на корень домена. С подпутём вроде `/my-vibe/` ссылки разъедутся: для этого в `site.config.json` есть `basePath`.

## Что править

Всё содержательное — в трёх файлах, потом снова `node src/build.mjs`.

| Файл | Зачем |
|---|---|
| `site.config.json` | Адрес сайта (`baseUrl`), промокод, телефон, тексты главной, флаг голосового ввода `voiceSearch` |
| `data/apartments.json` | Квартиры: цена, этаж, площадь, гости, флаг `active` |
| `src/build.mjs` | Тексты условий и FAQ, если их нужно переписать |

Цена «от» на главной и в `llms.txt` берётся из минимальной `priceFrom` среди квартир с `active: true`. Описание для поисковиков в `site.config.json` (`home.description`) при смене минимальной цены поправьте вручную.

Квартира с `active: false` не попадает на страницы, в JSON-LD, в `llms.txt` и в публичный `docs/apartments.json`.

Прямой ссылки Bnovo на конкретную квартиру в открытом модуле нет, поэтому кнопка «Забронировать» открывает общий модуль. Если появится адрес категории, положите его в поле `bookingUrl` этой квартиры.

## Фото

На главной два кадра: `view` (панорама из Galaxy) и `galaxy-435` (интерьер). У каждой квартиры своё фото, имя совпадает с `photo` в данных.

Файлы уже лежат в `new-volga/img/`: `{id}-480.avif`, `{id}-960.avif`, `{id}-480.webp`, `{id}-960.webp`. Сборка копирует их в `docs/img/`.

Чтобы заменить кадр, положите JPEG в `new-volga/photo-src/{id}.jpg` и выполните `node src/optimize-photos.mjs`, затем сборку. Нужен `ffmpeg`. Подпись картинки — поле `alt` у квартиры или у героя в конфиге.

## GitHub Pages и поддомен

Сайт рассчитан на бесплатный GitHub Pages и поддомен `volga.matveevapartments.ru`. Pages в этом репозитории не включён.

1. В репозитории: Settings → Pages → Build and deployment → Deploy from a branch.
2. Branch: `main`, folder: `/docs`, Save.
3. Custom domain: `volga.matveevapartments.ru`. Файл `docs/CNAME` уже содержит это имя.
4. У регистратора домена запись `CNAME`: `volga` → `matveevn8n-web.github.io`.
5. Дождаться сертификата. Canonical и Open Graph уже смотрят на `baseUrl` из конфига. Если адрес другой — поменяйте `baseUrl` и пересоберите.

## Вставка в Tilda

Домен `matveevapartments.ru` обслуживает Tilda, туда этот сайт целиком не встаёт без потери скорости: у Tilda свои скрипты. Рабочий вариант — поддомен выше и, если нужна старая страница, блок Tilda с iframe на `https://volga.matveevapartments.ru/`.

Вставить саму главную в HTML-блок Tilda можно только как запасной путь: у картинок и ссылок должны быть полные адреса с `baseUrl`, а не пути от корня. Скорость и «один экран» при этом уже не гарантируются.

## Бронирование и Метрика

Модуль Bnovo, uid `e358a8dd-e919-467b-989e-ce34e5b25142`. Виджет грузится после первой отрисовки. Пока он не пришёл, на его месте обычная форма: даты и гости уходят на `reservationsteps.ru`. Промокод **СНОВА** гость вводит уже в модуле.

Счётчик Метрики `104131379`, без Вебвизора. Цель «Бронирование» `684151483` на стороне reservationsteps.ru не менялась. Свои JS-цели, их нужно завести в Метрике с такими именами:

- `booking_click` — «Найти», «Забронировать», клик в виджете
- `phone_click`
- `whatsapp_click`
- `telegram_click`
- `promo_copy` — нажатие на оффер копирует код
- `voice_search` — кнопка «Сказать даты голосом» (только если браузер умеет Web Speech API)

Кнопка голоса включается флагом `voiceSearch` в конфиге.
